# UniFind – Campus Lost & Found Website

## About the Project

UniFind is a campus lost and found website prototype designed to help students find lost belongings and report items they have found on campus.

The website provides a simple interface where users can browse items, search for belongings, report lost or found items, and submit claims.

## Features

* Home page with recently reported items
* Browse lost and found items
* Search for items
* View item details
* Report lost or found items
* Create an account and log in
* Claim items
* View personal activity
* Responsive user interface
* Teal and mint green colour theme

## Technologies Used

* HTML
* CSS
* JavaScript
* Browser Local Storage

## How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

Alternatively, on Windows, run `START_HERE.bat` if it is included.

## Demo Account

1. Select **Login**.
2. Choose **Create an account**.
3. Enter your name, email address, and a password with at least 8 characters.
4. Log out and log in using the same details.

The Forgot Password feature is a local demonstration only. It does not verify email ownership or send password-reset emails.

## Project Limitations

This is a frontend-only prototype. It does not currently include a backend server or database.

* Accounts, reports, and claims are stored in the browser's Local Storage.
* Data is not shared between different devices or browsers.
* Clearing browser site data may remove saved demo information.
* University email addresses are not verified.
* Authentication is intended for demonstration purposes and is not suitable for production use.

A real public deployment would require a backend, database, secure authentication, email verification, and a verified password-reset process.

## Project Structure

* `index.html` – Website structure
* `styles.css` – Website styling and layout
* `app.js` – Frontend functionality
* `START_HERE.bat` – Optional Windows launcher
* `README.md` – Project documentation

## Purpose

This project demonstrates the design and frontend functionality of a campus lost and found platform. It can be extended with a backend and database in future development.
